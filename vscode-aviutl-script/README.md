# AviUtl Script

AviUtl スクリプト（Lua ベース）向けのシンタックスハイライトとスニペットを提供する VS Code 拡張機能です。

A VS Code extension providing syntax highlighting and snippets for AviUtl scripting (Lua-based).

## Features / 機能

- **シンタックスハイライト**: AviUtl スクリプト固有のキーワード、`obj` プロパティ・メソッド、セクションラベルをハイライト
- **スニペット**: 55 個のスニペット（関数、プロパティ、環境テンプレート）
- **Lua 継承**: Lua の標準シンタックスを拡張し、AviUtl 固有の構文を追加

## Supported File Types / 対応ファイル形式

| Extension | Description |
|-----------|-------------|
| `.obj` | オブジェクトスクリプト |
| `.anm` | アニメーション効果スクリプト |
| `.scn` | シーン切り替えスクリプト |
| `.cam` | カメラ効果スクリプト |
| `.aviutl-script` | 汎用 AviUtl スクリプト |

先頭行が `-- AviUtl Script --` のファイルも自動認識されます。

## Snippets / スニペット

55 個のスニペットが含まれています。エディタで入力を開始すると自動補完に表示されます。

### 使用例

```lua
-- 環境テンプレート: !env と入力
-- AviUtl Script --

-- obj メソッド: draw, load, mes などを入力
obj.draw(ox,oy,oz,zoom,alpha,rx,ry,rz)

-- obj プロパティ: ox, oy, alpha などを入力
obj.ox
```

### スニペット一覧（抜粋）

| Trigger | Description |
|---------|-------------|
| `!env` | AviUtl Script 環境テンプレート |
| `draw` | `obj.draw()` — オブジェクト描画 |
| `load` | `obj.load()` — ファイル読み込み |
| `mes` | `obj.mes()` — テキスト表示 |
| `effect` | `obj.effect()` — フィルタ効果実行 |
| `ox`, `oy`, `oz` | 座標プロパティ |
| `alpha` | 透明度プロパティ |
